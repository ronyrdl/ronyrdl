## 📂 Featured Projects

### 🏫 NexoEdu — Riwi × Mayor's Office of Barranquilla
A Web platform developed to manage and update student and graduate records across public schools in the District of Barranquilla. Capstone project deployed in production.

- **Challenge:** Student records were scattered across disconnected spreadsheets, making data tracking and updates inefficient.
- **Solution:** Developed a campaign-based tracking system that identifies eligible students, tracks updates, and generates real-time status indicators.
- **My Role — Frontend Developer:** Built the SPA frontend using Vanilla JavaScript (ES Modules), custom routing via History API, JWT authentication with automatic token refresh, centralized API service layer, and skeleton screens.
- **Tech Stack:** JavaScript (ES Modules) · Vite · Tailwind CSS v4 · Node.js · Express · PostgreSQL · Supabase · JWT · Render · Vercel.

### 🍽️ MANA — Restaurant Management System
A web-based restaurant management platform designed to centralize daily operations, order processing, menu updates, thermal printing integration, and sales analytics.

- **Challenge:** Manual order tracking caused bottlenecks during peak service hours and inaccurate end-of-day sales auditing.
- **Solution:** Created a centralized management portal with role-based access, product category management, live order tracking, and sales reports.
- **My Role — Full Stack Developer:** Designed and implemented the web application, developed RESTful API endpoints, integrated the SQLite database, and managed system layout and business rules.
- **Tech Stack:** Node.js · Express · SQLite3 · JavaScript · HTML5 · CSS3 · Bootstrap.

### 💎 Venus — Jewelry Catalog
A responsive digital catalog designed for customers to explore products, browse collections, check prices, and establish direct contact via social integrations.

- **Challenge:** The business needed an organized online presence to showcase items without setting up a full transaction-heavy e-commerce platform.
- **Solution:** Built a lightweight, responsive catalog with structured categorization and direct WhatsApp/Instagram lead routing.
- **My Role — Frontend Developer:** UI/UX structure, responsive web styling, and interactive layouts.
- **Tech Stack:** HTML5 · CSS3 · Bootstrap 5.3 · Font Awesome.
