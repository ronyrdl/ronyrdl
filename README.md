# 📂 Projects

### 🍽 MANA  
A local restaurant management and ordering system developed to manage menus, orders, sales, and daily statistics. The platform allows administrators to manage products and categories, process customer orders, and monitor sales information through a centralized interface.

### 🧩 The problem
The resturant needed a digital system to organize its menu, manage customer orders, track sales, and have better control over its daily operations. Managing this information manually made it difficult to keep orders, products, and sales organized in one place.

### 💡 The solution
I developed a web-based management system that centralizes the restaurant's main operations. The system includes administrator authentication, menu and category management, order creation and tracking, sales monitoring, and daily statistics, providing a more organized way to manage the restaurant.
####  👨‍💻 My role here

Full Stack Developer responsible for designing and developing the system, implementing the frontend interface, building the backend and REST API, integrating the database, and developing the order, menu, authentication, sales, and statistics functionalities.

**Tech Stack:** Node.js · Express · SQLite3 · JavaScript · HTML5 · CSS3 · Bootstrap

### 🏫 NexoEdu — Riwi × Mayor's Office of Barranquilla

Web platform for tracking and updating student and graduate records across public schools in the District of Barranquilla. Capstone project at Riwi in partnership with the city government, currently live in production.

### 🧩 The problem
Records lived scattered across spreadsheets and ad-hoc forms. They went stale quickly, and there was no way to tell when each record was last updated — leaving the city unable to track outcomes or run programs on reliable data.

### 💡 The solution
An update campaign system. Each campaign defines a scope (district-wide, by locality, neighborhood or school) and eligibility criteria; the system automatically resolves which students qualify and records who updated their data and when. A data-freshness indicator and progress metrics turn "is our data current?" into something measurable.

#### 👨‍💻 My role here
**Front-end:** a vanilla JavaScript SPA, no framework. Custom History API router, session- and role-based route guards, a service layer over the REST API, a centralized HTTP client with automatic token refresh, and a reusable component system with skeleton screens and parallel data fetching.
Stack: JavaScript (ES Modules) · Vite · Tailwind CSS v4 · Node.js · Express · PostgreSQL · Supabase · JWT · bcrypt · Swagger Deployment: front-end on Vercel · back-end on Render · database on Supabase
